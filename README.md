# HR-Recruiter

An HR recruitment management application designed to help manage recruitment-related activities through a centralized web application.

## Overview

HR-Recruiter is a recruitment-focused application that provides a structured way to manage HR and candidate-related information.

The project was developed to practice building a real-world business application, including backend development, database operations, application workflows, and deployment.

## Features

- HR and recruitment management
- Candidate-related data management
- Centralized recruitment workflow
- Database-backed application
- Backend API/application logic
- Web-based user interface
- Input validation and application error handling

## Tech Stack

### Backend
- Python
- Django
- SQLite

### Frontend
- JavaScript
- Web-based UI

### Tools & Deployment
- Git
- GitHub
- Render / Vercel
- Python 3.12
